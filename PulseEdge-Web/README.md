# PulseEdge AI

### Offline Multimodal Frontline Healthcare Risk & Referral Prototype

PulseEdge AI is an offline-first mobile prototype designed to support frontline healthcare workflows in connectivity-constrained environments.

## Problem

Frontline healthcare workers may need to capture patient observations, vitals and contextual information even when reliable connectivity is unavailable. Converting those observations into a structured and explainable referral workflow can be difficult in such environments.

## Solution

PulseEdge AI provides:

- Offline-first case capture
- Structured observation workflow
- Vital-sign safety validation
- Explainable risk escalation
- Referral summary generation
- Local data handling
- Mobile-first interface

## Core Workflow

Capture → Structure → Validate → Refer

## Prototype

The web prototype can be accessed through GitHub Pages.

An Android APK is also included for offline demonstration.

## Technology

- Android
- HTML/CSS/JavaScript
- Android WebView
- Local storage
- Deterministic rule-based safety layer
- Offline-first architecture

## Important

This is a hackathon prototype and is not a medical device or a substitute for professional clinical judgment.
